# ключи и данные

Токен бота — `secrets/bot_token`, ключ внешнего AI — `secrets/ai_api_key`. Права файлов0600, папки0700. Setup не принимает токен через аргументы командной строки

`.gitignore` исключает ключи, локальные настройки, базы, бэкапы и логи. Проверка `.githooks/pre-commit` дополнительно читает именно Git index и ищет ключи в коде. Для старых коммитов есть `scripts/check_repo.py --history`. Найденные значения не печатаются

Перед публикацией: проверить staged-файлы и историю. Если ключ уже попал в удалённый репозиторий, его нужно отозвать; удаление файла новым коммитом не удаляет ключ из старой истории

## аккаунты

Прямой запрос требует совпадения `from.id` и private chat. BusinessConnection привязан к своему владельцу и не переходит другому аккаунту

SQL-запросы архива сами проверяют владельца. TenantDB не фильтрует произвольный SQL. ID чужого сообщения, CID в URL или подделанный callback не дают доступа

Отправка проверяет получателя, права подключения, поколение аккаунта и путь файла. Поздний ответ после удаления аккаунта отбрасывается. Незавершённый HTTP-запрос уже нельзя отозвать

Удаление аккаунта каскадно удаляет его данные и собственную папку файлов. Минимальная запись об отключённом CID не даёт старым событиям заново включить архив. Независимые бэкапы и копии в Telegram не удаляются

## сеть

API привязан к localhost, Ollama и Whisper не публикуют порты наружу. Не выставлять8787 в Интернет без отдельной авторизации и защищённого канала

TikTok принимает публичные HTTPS-ссылки разрешённых доменов. Редиректы CDN и размер проверяются. Поиск ограничен512КБ XML и4 результатами, внешние страницы сервер не посещает. Внешний AI требует явного разрешения администратора, речь остаётся локальной

В логах нет содержимого ошибок HTTP и URL с токенами. Бэкапы содержат пользовательские данные, их нужно хранить отдельно с ограниченными правами
