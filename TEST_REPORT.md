# проверки

Все тесты выполняются на временных базах и файлах. Рабочий архив не используется для тестовых входящих сообщений

Покрыты архив/версии/удаления, сохранение, медиа, настройки и нижние кнопки. Отдельно — два аккаунта с одинаковыми ID чатов/сообщений, чужие пути, API, удаление аккаунта, отложенные ответы, рестарт и миграции

Также проверяются TikTok MP4/фото/лимиты/редиректы, поиск, голосовые, цитаты, stories с подтверждением, часы и восстановление имени/bio

Проверка репозитория тестируется на staged-ключе, удалённом секрете в истории, запрещённых файлах и безопасных изображениях

```bash
python -m pytest -q
ruff check smotritel scripts tests
ruff format --check smotritel scripts tests
docker compose --profile test run --rm --build --no-deps test
```

После правки: 266 тестов на машине и 266 в Docker, Ruff без ошибок
