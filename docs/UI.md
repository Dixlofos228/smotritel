# кнопки

Всё управление снизу, рядом с полем ввода

| слева | справа |
|---|---|
| Архив | Удалённые |
| AI | TikTok |
| Перевод | Яндекс |
| Погода | Summary |
| Изменённые | Сохранённые |
| Настройки | Ещё |

В «Ещё» — длинный список остальных действий, внизу Главная. Разделы, выбор чата/сообщения и подтверждения тоже используют нижнюю панель

Кнопка отправляет текст, маршрутизатор сверяет его с текущей панелью аккаунта. Одинаковые подписи получают отдельные номера. Старые inline-кнопки поддерживаются, новые сообщения их не создают

При вводе доступны основные разделы, Отмена, Главная и при необходимости Назад. Запрос, новая команда или переход убирают старую подсказку. Результат заменяет временный статус. Сообщения пользователя и уведомления архива не удаляются

Поздний ответ не сбрасывает выбранный раздел. После перезапуска панель сохраняется. Если клиент Telegram её скрыл, открыть кнопкой клавиатуры или `/start`

Фото открывает Цитата/Stories3×3. Голосовое — Расшифровать и кратко. Перевод предлагает язык, итоги — период, автоответы — свой чат и включение/выключение

Stories сначала показывают предпросмотр и ZIP. Публикация отдельной кнопкой. Premium и Send остаются демо. Чужие чаты и сообщения недоступны

«Яндекс» — название кнопки, поиск сейчас получает материалы Bing и возвращает ответ с источниками в чат. TikTok загружается через TikWM. Сервисы указаны перед вводом

Главная клавиатура RU/EN, подробная справка преимущественно русская. Тему, шрифт и emoji выбирает Telegram. ReplyKeyboard доступна в личке бота, для Business-сообщений Telegram её не поддерживает
