# несколько аккаунтов

Каждый пользователь нажимает Start и подключает свой Telegram Business. Глобального владельца бота для доступа к архивам нет

Аккаунт определяется проверенным отправителем или владельцем BusinessConnection. Подстановка чужого ID не меняет контекст запроса

Чаты могут иметь одинаковые message/chat ID у разных подключений. Ключ архива составной, выбор сообщения и файла дополнительно проверяет владельца

Настройки, API-ключ, часы, наблюдение, нижняя панель и ожидание ввода отдельные для каждого аккаунта. Тяжёлые задачи и отправка учитывают давно не обслуженных пользователей

Файлы разнесены по tenants/uid. Удаление своих данных не трогает другие аккаунты. При повторном Start создаётся новое поколение, старые отложенные ответы не возрождают прежние данные

Проверка: два отдельных аккаунта, разные тексты в чате с одинаковыми ID, отдельные настройки и удаление одного аккаунта. Автоматические сценарии лежат в tests/test_multi_user.py
