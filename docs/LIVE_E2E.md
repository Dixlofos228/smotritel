# проверка на сервере

1. Start → главная нижняя панель
2. Подключить Business, получить сообщение, изменить и удалить его
3. Проверить оригинал, версии, сохранение и файлы в архиве
4. AI → вопрос, дождаться ответа; подсказка и временный статус должны исчезнуть
5. Во время долгого запроса открыть Ещё/Настройки — результат не должен сбросить панель
6. Яндекс → запрос → информация и источники в чате
7. TikTok → публичное видео и фото, проверить скачанные файлы
8. Фото → Цитата/Stories, голосовое → расшифровка и итог
9. Отмена/другой раздел должны прекращать ввод
10. Повторить на втором аккаунте, чужие данные не должны открываться

Stories и часы проверять только на своём аккаунте с разрешёнными правами. Публикация требует подтверждения, выключение часов возвращает исходный текст

`scripts/status.py` читает Bot API и состояние сервера. `scripts/runtime_smoke.py` проверяет настоящие локальные модели с тестовым аудио

`scripts/live_smoke.py` отправляет проверочные сообщения только явно выбранному зарегистрированному аккаунту. Пользовательские входящие события не подделяет. API-отправка клавиатуры сама по себе не проверяет клиентские нажатия

Для бэкапов есть scripts/migration_check.py и тесты восстановления. Синтетические события тестов хранятся во временной базе
